## 📋 Prerequisites

### Required (One-Time Setup)

1. **Ngrok Installed**
   ```powershell
   ngrok version
   # If not found: Download from https://ngrok.com/download
   ```

2. **Ngrok Authenticated**
   ```powershell
   ngrok config add-authtoken YOUR_TOKEN
   # Get token from: https://dashboard.ngrok.com/get-started/your-authtoken
   ```

3. **Node.js Dependencies**
   ```powershell
   # Script will install if missing, or manually:
   cd backend && npm install && cd ..
   cd frontend && npm install && cd ..
   ```

4. **PostgreSQL Running** (Optional - frontend works without DB)
   ```powershell
   Get-Service postgresql*
   ```

## 🐛 Troubleshooting Quick Reference

| Issue | Quick Fix |
|-------|-----------|
| "ngrok not found" | Install: https://ngrok.com/download |
| "Authentication failed" | Run: `ngrok config add-authtoken TOKEN` |
| "CORS error" | Restart backend (already configured) |
| "502 Bad Gateway" | Backend crashed, restart script |
| "Blank page" | Clear cache or use incognito |
| "Cannot connect to DB" | Start PostgreSQL service |
| "Session timeout" | Re-run script (free account limit) |

**Full troubleshooting:** See `NGROK_SETUP.md`
